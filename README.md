# LAZUR-IT — веб-студия

Лендинг веб-студии **LAZUR-IT** и готовое коммерческое предложение в PDF,
выполненные в стилистике древнеегипетской культуры: золото, лазурит, бирюза
и ночное небо — палитра, выведенная из фирменного знака (скарабей с ладьёй крыльев).

## Что внутри

| Путь | Назначение |
| --- | --- |
| `index.html` | Лендинг: hero, принципы студии, услуги, кейсы, стек, процесс, о студии, контакты с формой заявки |
| `assets/css/style.css` | Дизайн-система и стили лендинга (токены, компоненты, адаптив) |
| `assets/js/main.js` | Интерактив без зависимостей: меню, scroll-spy, появление блоков, счётчики, прогресс чтения, форма → `mailto:` |
| `assets/img/` | Логотипы (марка, полный, исходник с фоном), favicon и apple-touch-icon |

> **Коммерческое предложение в этом репозитории не хранится.** Готовый PDF и его
> вёрстка содержат банковские реквизиты, поэтому держатся отдельно от публичного
> кода — только на рабочей машине. Лендинг на них не ссылается.

## Технологии

- Чистый **HTML5 + CSS3 + ванильный JavaScript** — без сборки, зависимостей и фреймворков.
- Шрифты Google Fonts: **Cinzel** (заголовки, римский капитул — как в вордмарке) и **Manrope** (текст).
- Иконки — собственный SVG-спрайт (`<symbol>` + `<use>`), включая декоративные
  египетские мотивы: скарабей, анкх, глаз Хора, солнечный диск, вода.
- Прогрессивное улучшение: без JS страница остаётся читаемой и навигируемой.
- Поддержка `prefers-reduced-motion` и печати.

## Локальный запуск

```bash
# из корня проекта
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

Или просто откройте `index.html` в браузере — страница полностью статическая.

## Коммерческое предложение (вне репозитория)

Готовый PDF и его вёрстка держатся в локальном комплекте рядом с проектом,
вне git: шаблон + стили + скрипт сборки + готовый PDF. Правки в тексте, суммах
или реквизитах вносятся в шаблон, после чего PDF пересобирается одной командой
(`bash build.sh`) — скрипт рендерит шаблон headless-браузером в A4.

В блоке подписей оставлены пунктирные поля **«М.П. / место для печати»** —
отдельно для Исполнителя и для Заказчика. Оттиск печати ставится поверх них
после подписания; в файле печать намеренно не проставлена.

## Форма заявок

Заявки уходят через **FormSubmit** — сторонний сервис, поэтому своего бэкенда не
нужно: сайт статический, а браузер посетителя отправляет запрос напрямую в сервис
через `fetch`. Если на хостинге появится PHP, заявки можно переключить на свой
скрипт `deploy/send.php` — тогда капча проверяется ещё и на сервере (см. DEPLOY.md).

### Включение (без регистрации)

1. Отправьте заявку через форму на сайте — на `lmax-work@ya.ru` придёт письмо
   от FormSubmit со ссылкой **«Activate Form»**.
2. Перейдите по ссылке (проверьте папку «Спам») — это одноразовое действие.
3. После этого заявки будут приходить на почту автоматически.

Регистрация, панель и пароль не нужны.

### Как это работает

- Посетитель заполняет форму и нажимает «Отправить заявку» → JS собирает
  `FormData` и отправляет её в FormSubmit. Кнопка на время отправки блокируется,
  на странице появляется «Спасибо! Заявка отправлена» — почтовый клиент не
  открывается.
- Отправляется именно `FormData`, а не JSON: такой запрос считается «простым»,
  браузер не делает preflight, и запрос проходит с любого статического хостинга.
- Если в поле «Способ связи» указан e-mail, он подставляется как **Reply-To**
  (`_replyto`) — можно отвечать прямо из почты.
- **JS выключен** — форма отправляется обычным POST (`action` у формы) и
  возвращает посетителя с `?sent=1`, где показывается благодарность.
- Письма приходят таблицей (`_template=table`), от спама стоит скрытая
  ловушка `_honey`.
- Если сервис недоступен, посетитель увидит сообщение с вашими прямыми
  контактами вместо пустого экрана.

### Смена сервиса

В `assets/js/main.js` есть переключатель:

```js
var PROVIDER = 'formsubmit';   // 'formsubmit' | 'formspree' | 'mailto'
var LEAD_ENDPOINT = '';        // '/send.php' — свой приёмник заявок на хостинге
var FORMSPREE_ID = 'YOUR_FORMSPREE_FORM_ID';
```

- `formsubmit` — как выше, без регистрации.
- `formspree` — зарегистрируйтесь на <https://formspree.io>, создайте форму и
  вставьте её ID (бесплатно 50 заявок/мес, зато письма идут от сервиса и не
  попадают в спам).
- `mailto` — вернёт прежнее поведение: форма готовит письмо и открывает
  почтовый клиент.

> **Web3Forms здесь не используется намеренно.** Сервис закрыт Cloudflare-челленджем
> (`cf-mitigated: challenge`), который невозможно пройти из `fetch`-запроса —
> браузер получает `Failed to fetch`. Проверено.

### Капча «одним кликом»

В форме стоит **Cloudflare Turnstile** — капча без выбора картинок, обычно
проходит незаметно для человека. Ключи и домены настраиваются в
`dash.cloudflare.com` → Turnstile.

```js
var CAPTCHA_PROVIDER = 'turnstile';                 // 'turnstile' | 'smartcaptcha' | '' (выключена)
var CAPTCHA_SITE_KEY = '0x4AAAAAAFYLhAKy0EwbUott';  // site key — публичный, ему место в коде
```

| Сервис | Где взять site key | Особенности |
| --- | --- | --- |
| **Cloudflare Turnstile** | `dash.cloudflare.com` → Turnstile | тёмная тема, русский язык, обычно проходит без клика |
| **Яндекс SmartCaptcha** | `console.yandex.cloud` → SmartCaptcha | российский сервис, данные в РФ |

**Secret key в код не попадает.** Он нужен только серверу для проверки токена
(`deploy/send.php`) и передаётся переменной окружения `TURNSTILE_SECRET` либо
файлом `turnstile-secret.php`, который исключён из git.

**Домены.** В настройках виджета → *Hostname management* должны быть перечислены
адреса, где открывается форма: `lazur-it.ru` (корневой домен автоматически
покрывает поддомены, включая `www`) и `lbnvwork.github.io` — пока живёт демо на
GitHub Pages. Для домена, которого нет в списке, виджет вернёт ошибку 110200 и
покажет «Ошибка» вместо галочки — подробнее в DEPLOY.md.

Как это ведёт себя:

- Капча не пройдена → отправка не уходит, посетитель видит подсказку
  «Отметьте, пожалуйста, галочку “я не робот”» и страница подъезжает к виджету.
- Капча пройдена → заявка отправляется, а виджет сбрасывается для следующей.
- **Виджет не поднялся** (блокировка, медленная сеть, ошибка ключа) → посетителя
  не держим: заявка всё равно уходит. В письме при этом будет поле
  `captcha: widget-unavailable`, так что такие заявки видно.

### Что стоит помнить

- Письма FormSubmit уходят не с вашего домена — первые заявки проверьте в папке
  «Спам» и отметьте как «не спам».
- В скрытом поле `_next` указан адрес возврата после отправки без JS:
  `https://lazur-it.ru/?sent=1#contact`. Если домен изменится — поправьте и здесь.
- Свой приёмник заявок включается одной строкой — заявку принимает скрипт на
  хостинге, сам проверяет токен капчи и отправляет письмо с вашего домена:
  ```js
  var LEAD_ENDPOINT = '/send.php';   // пусто — отправка идёт в FormSubmit
  ```
  Файл скрипта — `deploy/send.php`, порядок настройки — в DEPLOY.md.
- **Secret key Turnstile** хранится только на сервере и в git не коммитится.
  Если он где-то засветился — перевыпустите его в панели Cloudflare.
